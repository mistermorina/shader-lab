# Agent Workflow

1. Nutze zuerst Graphify, bevor du viele Rohdateien liest.
2. Frage den Graph nach Architektur, Routing, Komponenten und Datenfluss.
3. Oeffne danach nur die konkreten Dateien, die Graphify als relevant nennt.
4. Nutze RTK fuer laute Terminal Outputs.
5. Lies keine Secrets, keine `.env*` Dateien und keine lokalen Datenbankdateien.
6. Dokumentiere neue Erkenntnisse in `docs/ai`.
